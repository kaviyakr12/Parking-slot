Smart Parking Slot Allocation System

Why it is used:
To efficiently manage parking spaces and reduce congestion by automatically tracking slot availability and usage.

How it works:
The system monitors parking slots in real-time and uses color-coded indicators — green for available, red for occupied with fine, and yellow for nearing time limit. It dynamically allocates slots to incoming vehicles and updates the interface for easy monitoring.

Tech Stack:
HTML, CSS, JavaScript, Python (optional backend), and responsive web design

Impact:
Enhanced parking efficiency with real-time updates, dynamic allocation, and a user-friendly web interface.
